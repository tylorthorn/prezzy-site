Prezzy Studio — OpenAI 相容 API

Base URL: https://prezzy-site.<你的子域>.workers.dev

無需註冊即可使用（匿名限流），或建立 API Key 取得更高額度。

POST /v1/images/generations（同步）
{
  "model": "flux-klein",          // 見 GET /v1/models
  "prompt": "a cute orange cat",
  "size": "1024x1024",            // 或 1792x1024 / 1024x1792 / 1536x1024 …
  "quality": "standard",          // 可選
  "negative_prompt": "blurry",    // 可選（FAA 擴充）
  "response_format": "url"        // url | b64_json
}
→ 200
{
  "created": 1730000000,
  "data": [{ "url": "https://cdn-ap.rockhr.ai/...", "revised_prompt": null }],
  "faa": { "upstream": "aiart", "upstreamModel": "Flux 2 Klein", "ratio": "1:1" }
}
POST /v1/videos/generations（非同步）
{
  "model": "wan-2-2",   // wan-2-2 | hunyuan-1-5 | ltx-2
  "prompt": "a cat walking through a neon street"
}
→ 202 { "id": "uuid", "object": "video", "status": "submitted" }
→ 輪詢 GET /v1/jobs/:id（每 5 秒）直到 "status": "completed"，data[0].url 為影片位址
其他端點
MethodPath說明
GET/v1/modelsOpenAI list 格式模型清單
GET/v1/media?url=媒體代理（UI 渲染 / 下載，加 &download=1）
GET/v1/jobs/:id影片任務輪詢
GET/api/keys管理 Key（需 Admin Token）
POST/api/keys建立 Key
DELETE/api/keys/:id撤銷 Key

認證：Authorization: Bearer sk_pz_...；管理端點需 X-Admin-Key: <ADMIN_TOKEN>

OpenAI SDK 範例
import OpenAI from "openai";
const client = new OpenAI({
  baseURL: "https://prezzy-site.<子域>.workers.dev/v1",
  apiKey: "sk_pz_...",
});
const img = await client.images.generate({
  model: "flux-klein", prompt: "a cute cat", size: "1024x1024",
});
console.log(img.data[0].url);
